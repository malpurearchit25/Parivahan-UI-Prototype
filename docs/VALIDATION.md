# Validation

Verified in the browser during preparation:

- All twelve overview guides render.
- Vehicle filter returns four cards; searching for tax returns one guide.
- Vehicle and driving licence sample buttons display their matching fictional records.
- The tax service opens its named dialog with three guide steps; the close control works.
- The local help panel displays its scripted explanation and closes.
- At a 390-pixel phone viewport the page fits without horizontal overflow and the menu expands.
- Desktop and phone hero layouts were visually inspected.

Automated repository checks validate local page/asset references, fragment targets, unique IDs, heading presence, external new-tab isolation, and JavaScript syntax.

These are focused checks, not a full assistive-technology or cross-browser certification. No production government integration is implemented or tested.
